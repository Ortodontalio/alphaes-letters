# 🚀 OpenLetters v2.0 — Major Update

The mod has been completely renamed to **OpenLetters** and is taking things to a whole new level! In this version, the internal architecture was completely overhauled, an addon system was added, along with new mechanics, dozens of new blocks, and colors. This is the biggest update in the mod's history.

### 🎉 Global Changes

**New Name:** The mod has been officially renamed from `AlPhAE's Letters` to `OpenLetters`.<br/>
**New Version:** The mod version has been updated to **2.0**.<br/>
**Minecraft Update**: The base game version has been updated from `1.21.3` to `1.21.4`.<br/>
**Java Update:** The mod has been migrated to `Java 21` (instead of `Java 17`).<br/>
**Fabric Loader Update:** Requires **Fabric Loader** version `0.19.3` or higher.<br/>
**New Icon:** The mod has received a new logo.<br/>
**Source Code Link:** A direct link to the GitHub repository has been added to `fabric.mod.json`.<br/>

### ✨ New Features

#### 🧩 Custom Addon System

Now you don't need to wait for a mod update to add new characters!
Just drop a JSON model file into the `./mods/openletters/` folder.
The mod will automatically generate the block, models, recipes, loot tables, and the `mineable/pickaxe` tag on the fly.
Addons are loaded as a built-in resource pack (`openletters_generated`), ensuring full compatibility with other mods.
The tooltip for custom letters now displays the **Author** and **Addon Version**.
A counter has been added to the Title Screen, showing how many OpenLetters addons are currently loaded.

#### 🌫️ "Exfoliation" Mechanic (Oxidation)

Rich Ferroconcrete now behaves like copper! Over time, it can "exfoliate" (fade).<br/>
**Speeding up the process:** You can accelerate the fading by using a regular brush. This will peel off some of the paint from the rich ferroconcrete.<br/>
**Restoring color:** You can return the block to its original look, but you will need to craft the corresponding dye and apply it to the exfoliated ferroconcrete. However, this won't work if the exfoliated concrete has already turned into regular ferroconcrete.<br/>
**Configuration:** If you don't like this effect, you can easily disable it in the world settings via the new game rule `exfoliationEnabled` (Ferroconcrete Exfoliation).

#### 🖼️ Frame Block

The **Strikethrough Block** has been completely reworked and renamed to **Frame**.<br/>
**Crafting:** Crafted using 8 sticks and a dye in the center of the crafting table.<br/>
**Repainting:** The frame can be repainted directly in the crafting table by adding a dye.<br/>
**New Use:** The frame can now be used to craft an `Item Frame` and a `Painting`.<br/>
**Placement on letters:** The frame can be placed on any letter to create a colored cover. It can be removed with a hoe (dropping sticks).<br/>

#### 🔄 Safe World Migration

If you played the old version of the mod, don't worry about your builds!
A background handler (`BlockMigrationHandler`) has been added, which automatically and safely converts old `Cropped Ferroconcrete` blocks into regular rich ferroconcrete with an additional letter block upon chunk loading, without any data loss.
The migration works asynchronously and doesn't cause lag: it processes no more than 50 blocks per tick.
A migration versioning system (`BlockMigrationState`) has been added for future updates.

### 🧱 New Blocks and Items

#### 🌈 Full Color Palette (16 Colors)

Full colored versions have been added for all technical blocks. Now your signs can be truly colorful!
* 16 colors of Rich Ferroconcrete: from white to black.<br/>
* 16 colors of regular Ferroconcrete (Concrete with Bars).<br/>
* 16 colors of Exfoliated Ferroconcrete.<br/>
* 16 colors of Ferroconcrete Powder.<br/>

#### 🔤 New Diacritic Characters

New letters for international alphabets have been added to the Latin alphabet:
* Â (A with circumflex)
* Č (C with caron)
* Ş (S with cedilla)
* Ű (U with double acute)

#### ⛏️ Smart Mining

**Ferroconcrete Powder**, **Ferroconcrete**, and **Rich Ferroconcrete** will now spawn Iron Bars in their place if broken without the `Silk Touch` enchantment.<br/>
Loot tables for all letters now preserve the `lit` and `color` properties when mined.

### 🎨 Visual Improvements

#### 🚧 Unique Fences and Gates

The 3D models for the **Iron Fence** and **Iron Fence Gate** have been completely rewritten and reworked.
They no longer use vanilla Minecraft templates, but have their own detailed hitboxes and geometry, perfectly fitting the mod's industrial style.
Models for all states have been updated: post, side, inventory, open, wall, wall_open.

#### ✨ New Custom Tint System

A custom tint type `multi_color_tint` has been added, allowing blocks and items to have multiple independent colors (e.g., the color of the letter itself and the color of the cover/frame).

### 🛠️ Technical Changes (Under the Hood)

#### 🏗️ Migration to DataGen

Hundreds of hardcoded JSON files (`blockstates`, `models/block/letter_block/`, `items/`) for all base letters and technical blocks have been removed from the repository.<br/>
All generation of states, models, items, loot tables, and recipes has been completely moved to automatic data generation (`DataGen`) during the mod build.<br/>
New providers have been added: `ModelGenerator`, `LetterItemDefinitionProvider`, `LootTableGenerator`, `CustomRecipeGenerator`.
This significantly simplifies mod maintenance, adding new letters, and reduces the resource pack size.

#### 🔄 Complete Registration Overhaul

Obsolete abstract classes `BlockRegistrator` and `BlockItemRegistrator` have been removed.<br/>
Transitioned to static registration of blocks and items via the `Blocks.register()` and `Registry.register()` utilities.<br/>
A new `Registrable<T>` interface has been added to unify registration.<br/>

#### 🧬 New Mixins

`TitleScreenMixin` — displays the loaded addons counter on the main screen.<br/>
`ResourcePackManagerMixin` — loads addons as a built-in resource pack.<br/>
`SerializedChunkMixin` — prepares for chunk NBT migration.<br/>

#### 📦 New Item Tags

New tags have been added to unify recipes and mechanics:<br/>
`LETTER_POWDER_BLOCKS` — all types of Ferroconcrete Powder.<br/>
`LETTER_CONCRETE_BLOCKS` — all types of Rich Ferroconcrete.<br/>
`LETTER_EXFOLIATED_CONCRETE_BLOCKS` — all types of Exfoliated Ferroconcrete.<br/>
`CONCRETE_WITH_BARS_BLOCKS` — all types of regular Ferroconcrete.<br/>

#### 🎨 LetterBasic Rework

`LetterBasic` now inherits from `BlockWithEntity` (instead of `Block`), allowing it to store additional data (e.g., frame color) in the `BlockEntity`.<br/>
A new `HAS_COVER` property has been added to display the frame on the letter.<br/>
An `afterUseHoe` method has been added to remove the frame and drop sticks.<br/>

#### 🌍 Localization

Full translation of all new blocks (16 colors × 4 types = 64 new blocks) into English, Russian, and French.<br/>
Russian localization cleanup: Base letters in the Russian translation have been cleared of weird prefixes (e.g., "Буква Алфавита A" → just "Буква A"). Now the names look neat and readable.<br/>
Technical block name updates:<br/>
* `Strikethrough Indicator` → `Frame`.
* `Blue Ferroconcrete` → `Rich Blue Ferroconcrete`.
* `Ferroconcrete Powder` → `White Ferroconcrete Powder`.

#### 🐛 Bug Fixes

**Typo fix:** The Latin letter I now uses its own model instead of the H model.<br/>
**Localization fix:** Fixed incorrect prefixes in the Russian localization of base letters.<br/>
**Recipe fix:** Recipes for Ferroconcrete Powder now use the correct item tags.<br/>

### 📝 For Developers and Modders

If you want to create your own addon with custom letters, it's now easier than ever:<br/>
1. Create a JSON file with a model in Minecraft format (with `elements`, `faces`, `textures` fields).
2. Add `name`, `author`, `version` fields to the root of the JSON.
3. Drop the file into the `./mods/openletters/` folder.

Done! The mod will automatically generate the block, item, stonecutter recipe, loot table, and tag.<br/>
